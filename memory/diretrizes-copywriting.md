# Copywriting pointer

The full guide is `estrategia/10-copywriting.md`. Read the sections that match the piece before writing. Do not rely on memory of this file.

Apply it to every hook, script, carousel, caption, short video, and long post.

## What wins when two docs disagree

| Topic | Follow this | Role of the copy guide |
|---|---|---|
| Long-form voice | `memory/estilo-de-escrita/guia-voz.md` | Structure. The voice file owns person, punctuation, and words to avoid. |
| Hook | `memory/feedback_hook_writing_no_jargon.md` and `referencia/swipe-openers.md` | Families, formulas, and tests. The jargon rule still wins. |
| Ranking and persuasion | `memory/growth_sales_critical_lens.md` | How those signals change the line. |
| What to run this week | `memory/estrategias-principais.md` | — |
| Goal | `estrategia/01-posicionamento-e-pilares.md` | Email, offer, and a direct sell stay parked while the goal is growth or authority and nothing is for sale. |
| Carousel caption length | `memory/feedback-carousel-pipeline.md` | 1 to 3 sentences. The slides carry the lesson. |
| On-screen captions | `memory/feedback-video-editing-pipeline.md` | At most 5 words a cue. The copy guide does not override that. |
| Order of work | The pipeline for the task | Interview, research, write, approval. |

## When a correction sticks

A reusable copy correction is saved in `estrategia/10-copywriting.md`. If it also changes how a pipeline runs, add one line to that pipeline or to this pointer in the same sitting. Say so in the chat.

Pairs: `memory/diretrizes-trafego.md` (distribution) and `memory/diretrizes-hormozi.md` (offer).
