# Feedback loop

A correction from the creator is saved in `memory/` when it is a reusable preference: a rule, a voice choice, a layout number, a tool gotcha.

Save it in the moment, in the file that the next session will read for that task. Say in one line that it was saved.

When the correction is clearly a one-off for this piece, do not turn it into a rule. When it is unclear, ask once.

Do not store the note in a tool's private memory. `memory/` in this folder is the only project memory.
