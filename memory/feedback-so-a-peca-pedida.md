# Deliver only the piece that was named

## One piece at a time

When the conversation already holds several pieces (a take, cards, a call to action), deliver only the one the creator named. Then wait. Do not attach a suggestion they did not ask for.

## Someone else's post is a form reference

When the creator sends another account's post to study, use it for structure and picture: sequence, template, type, rhythm. The subject still comes from this brand's pillars. Each piece follows only the reference that was studied for it. Do not mix references.

When the reference is a rhythm, measure it cut by cut and reuse the duration by position. Do not copy the other account's words.

## The creator may write the script

`writes_scripts` in `memory/config.md` is `yes` or `no`.

- `no` — the agent writes the script, as the script pipeline says.
- `yes` — an idea or a research request comes back as research: checked facts, angles, and sources. No spoken lines, no script table, no hook, and no caption. Step 3 of the script pipeline runs only when the creator explicitly asks for a script.
- Empty on a copy whose `status` is already `ready` — ask once, write the key, and do not reopen onboarding. Ask before producing a script.
