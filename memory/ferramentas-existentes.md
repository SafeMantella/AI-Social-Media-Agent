# Tools the creator already uses

Filled by onboarding question 1b. Local to this copy. The rule is to integrate, not to replace. The creator keeps their tool. A toolkit tool fills a job only when the creator has none.

How a tool connects, in this order of preference: `connector` (MCP server already installed, check `claude mcp list`), `cli` (a command on this machine), `chrome` (Claude in Chrome, the creator's logged-in browser), `manual` (the creator drops a file or pastes text). Write `none` when there is no way in yet.
