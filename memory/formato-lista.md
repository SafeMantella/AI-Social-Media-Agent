# List pieces

These rules apply when the piece is a list. Measures below came from one copy. Re-measure before treating a number as fixed.

## Order is a retention choice

Explain the order in one line per position before building.

- The first two items stop someone who is scrolling.
- The middle alternates mood.
- A strong item sits near the end.

## Do not repeat an item

Before selecting, read the earlier list pieces in the store. An item already used goes in a reserve, not in the new list.

## Official image

Each item needs its official image. An item without one goes to a reserve. Tell the creator before the assembly.

## Choosing images

Search widely, then send one numbered sheet of 6 to 8 options and the recommendation. The creator picks by number. The tool contract is `ferramentas/buscar-imagens/README.md`.
