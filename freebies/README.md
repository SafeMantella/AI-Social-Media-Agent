# Freebies

One lead magnet, one folder. The pain comes from research or from replies, not from a guessed trend.

```
freebies/<slug>/
  escopo.md      # who it is for, the pain, the promise, the delivery word
  guia.md        # the piece itself. Source of truth
  lancamento.md  # hook, script, caption, DM setup
  resultados.md  # what happened after it shipped
```

Delivery, when Instagram DM automation is on, uses the trigger word in `memory/dm-automation.md`. The word is capitals with no accent. Message 1 asks for the address. Message 2 sends the link.

Do not ship a freebie that `estrategia/01-posicionamento-e-pilares.md` would refuse.
