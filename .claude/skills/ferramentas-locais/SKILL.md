# External tools

Read `memory/config.md` before running an account tool. A key set to `no` means do not run it. If a login fails, stop and ask the creator to reconnect. Do not switch stores. Ids for the Canva brand kit, masters, and assets live in `estrategia/marca/ids.md`. Never paste those ids into other files.

- **Notion** — used when `storage` is `notion`. Check that the Notion MCP server is connected before fetching. In Claude Code that check is `claude mcp list`. Do not reconnect a server that is already connected. Database links, once onboarding has written them, are in `estrategia/02-arquitetura-notion.md`. When `storage` is `md`, the store is `conteudo/` and Notion is not used.
- **Canva** — used when `carousel` is `canva`. Check that the Canva MCP server is connected the same way. **Rule that still holds:** never use `generate-design` (AI generation) for a carousel. Duplicate the master whose id is in `estrategia/marca/ids.md`, and edit natively. Never create a new text box from scratch. When `carousel` is `md`, the markdown file is the piece and Canva is not used.
- **Web search** — use the agent's own web search. It does not need a separate reconnect.
- **Fontastic** (`ferramentas/fontastic-text-image-generator/`) — local text-to-image. Python with Pillow and fonttools (`pip install pillow fonttools`). Usage: `python txtgen.py <text_size> "<text>" <font_path> <color> <output_path> [--weight N] [--instance NAME] [--bg transparent|hex] [--padding N]`. Full syntax and the bugs already fixed are in that tool's README. It is its own nested git repo, separate from this project.
- **Instagram or TikTok transcript** (`ferramentas/instagram-transcript/`) — downloads an Instagram reel or post, or a TikTok video (`yt-dlp`), and transcribes the audio locally (`whisper`, no paid API). `--comments` saves the top 15 comments by likes. Usage: `python3 ferramentas/instagram-transcript/instagram_transcript.py "<url>"` with the logged-in browser session the tool README describes. **Instagram and TikTok both need that session** (a browser that is logged in). Without it, yt-dlp gets an empty response (Instagram) or an IP block (TikTok). TikTok also needs a residential IP. **macOS gotcha:** reading the browser session directly raises the keychain prompt on every call. For a batch, export the session once and reuse the session file so the keychain is not touched. Detail is in the README. A batch helper for a saved-posts list may be in that folder. Use it only for a list the creator still wants. Dependencies: yt-dlp, `curl_cffi` (`>=0.7,<0.14`, required for TikTok and Instagram impersonation), openai-whisper, ffmpeg. This replaces a paid transcript API for "I found this video and want a transcript". **It does not discover videos.** Run it only when `instagram_research` is `yes`. See the README.
- **PDF to Markdown** (`ferramentas/pdf-to-markdown/`) — converts a PDF to markdown locally with `pymupdf4llm` (automatic local OCR fallback on pages that have no text layer). No API and no cost. Usage: `python3 pdf_to_md.py "<file.pdf>"`. Use it to read a long PDF without spending an image call per page. The tool README has the fallback if the extraction is bad. **Companion `epub_to_md.py`:** same folder, EPUB to markdown via `ebooklib` and `html2text` (dependencies already installed). No pandoc and no calibre. Usage: `python3 epub_to_md.py "<a.epub>" ["<b.epub>" ...]`. Output in `output/<name>.md`.
- **last30days** (`ferramentas/last30days-skill/`) — searches and synthesizes what real people said in the last 30 days. Run it only when `last30days` is `yes`. Sources that actually work (check with the tool's doctor command): Reddit (unstable, 429s), YouTube, Hacker News, GitHub, X (unstable). **TikTok and Instagram are OFF** inside this tool. Turning them on would require a paid third-party setup. That was a deliberate no. The advertised credit pool is not the real one-time pool. Detail: `memory/last30days_case_study_research.md`. Polymarket does not resolve on this network. Usage: `python3 ferramentas/last30days-skill/skills/last30days/scripts/last30days.py "<topic>" [--quick|--deep] --emit md --output "<path>.md"`. **`--emit md` alone does not write a file.** Pass `--output` (or `--save-dir`) as well. For a marketing topic, a platform-algorithm topic, or something fresh that sits outside Reddit, Hacker News, GitHub, and YouTube: if two tries return nothing usable, fall back to web search. Do not keep retrying. Used to check case studies in `referencia/estudos-de-caso/`, fresh market numbers, and trend angles.
- **Scrapling** (isolated environment in `ferramentas/scrapling/`) — adaptive scraping with an anti-bot bypass. Good for case-study research (sites behind a challenge, which covers the evergreen hole in `last30days`) and for collecting URLs to feed `last30days`. **It does NOT cover Instagram or TikTok** (tested: `get` returns a challenge image or a loading screen, `fetch` hits a real Instagram login wall — that is auth, not anti-bot — and a TikTok slider challenge that `--solve-cloudflare` does not solve). For Instagram, use `minet` below, and only when `instagram_research` is `yes`. There is no free TikTok path from here (`memory/tiktok_scraping_evaluated.md`). **Call the wrapper `ferramentas/scrapling/scrapling`.** There is no global `scrapling` on purpose: `scrapling[fetchers]` wants `curl_cffi>=0.16.1`, which breaks yt-dlp impersonation in `instagram-transcript`. Usage: `ferramentas/scrapling/scrapling extract <get|fetch|stealthy-fetch> "<url>" out.md --ai-targeted [-s "<css>"]`. Escalate `get` (HTTP) → `fetch` (JS) → `stealthy-fetch --solve-cloudflare` (protected). **Always `--ai-targeted`** (protection against prompt injection from the HTML). The extension sets the format (`.md` needs `markdownify`, already installed; also `.txt`, `.html`, `.json`). An MCP server exists and was postponed. Full syntax, flags, and gotchas: `ferramentas/scrapling/README.md`.
- **reddit-answers** (`ferramentas/reddit-answers/`) — Reddit Answers, top posts, and threads with score and percent upvoted, through the tool's own logged-in browser profile. **Read only. Never post, comment, or vote.** `reddit-answers login` once, then `reddit-answers research "<question in English>" -d folder/ -t 12`. The window stays off-screen. Headless is blocked. Run it only when `reddit` in `memory/config.md` is `manual` or `auto`. `auto` can conflict with Reddit's rules, and the account can be limited. The research workflow is `.claude/commands/pesquisar.md`. Detail: `memory/reddit_answers_tool.md`.
- **minet** (isolated environment in `ferramentas/minet/`) — web-mining CLI (médialab / Sciences Po). It covers **only the Instagram side** of discovery without a paid API. It uses the logged-in browser session. Run it only when `instagram_research` is `yes`. **Works:** `minet instagram hashtag`, `user-posts`, `user-followers`, `user-following`, `comments`, `user-infos`, `location` (hashtag and user-posts return real posts with caption, likes, and comments; `user-infos` is sensitive to rate limits). Also `minet fetch`, `scrape`, `resolve`, and `crawl` (web mining, no auth). **`minet tiktok search-videos` is BROKEN.** TikTok returns an empty 200. The endpoint wants a device signature the tool does not make. It is not the session. **TikTok scraping does not work for free from this machine.** minet, Scrapling, and the TikTok API that was tested and removed are all blocked without a residential proxy (`memory/tiktok_scraping_evaluated.md`). A manual browser capture is the only path that has worked. It was not adopted. Do not retry without a proxy. **Session export:** the built-in grabber does not read the local browsers on this machine. Export the session the way `ferramentas/minet/README.md` describes, and pass it on the auth flag that README names. Do not print the session. It stays out of git. The session expires (days or weeks). The failure is `401 require_login`. Export again. **Rate limit is aggressive. Space the searches out.** Call the wrapper `ferramentas/minet/minet`. Detail: `ferramentas/minet/README.md`.
- **keyword-mining / `suggest.py`** (`ferramentas/keyword-mining/`) — mines the real search terms around a seed from **Google and YouTube autocomplete** (public endpoint, no key, no cost). Groups them into **Pains / Questions / Comparisons / Intent / Related**. The first two sections are what a person types when they have the problem. That is raw material for a hook. Usage: `python3 ferramentas/keyword-mining/suggest.py "<seed>" [--no-alpha] [--lang <code>] [--out terms.md]`. `--no-alpha` is the fast pass (about 40 terms, focused on pain). Without it, the sweep is exhaustive (about 700). It is a step of the research workflow. See `ferramentas/keyword-mining/README.md`.
- **prep-frames / prep-texto / token-saver** — local prep so a later read costs less. `ferramentas/prep-frames/prep-frames video|image [-n 9]` writes `sheet.jpg` (a contact sheet) and `resumo.md` (OCR and faces via the on-device vision framework). Read those two instead of N frames. Open a full frame only to fine-tune an overlay. `ferramentas/prep-texto/prep-texto <file> [--max 40]` writes an index with line numbers. Then read with an offset and a limit. Never use it on a rules doc. `ferramentas/transcrever/leitura.py` writes a compact `.leitura.txt` (read that, not the JSON). The `ferramentas/token-saver/` hook refuses, once, a raw read of an image over 150 KB or a text over 30 KB (a file read, a `cat`, and a second fetch of the same page) and points at the prep. Detail: `memory/token-saver-prep-local.md`.
- **extrair-audio** (`ferramentas/extrair-audio/extrair-audio`) — extracts audio from videos **without re-encoding** (`-c:a copy`, bit for bit; the container follows the codec; an unusual codec falls back to FLAC). `ferramentas/extrair-audio/extrair-audio "<folder or video.mp4>"` writes `audio/` next to the video. `-o "<destination>/" ` overrides the destination. Accepts a file or a folder. Step 1 of an audio cleanup: extract, then Adobe Podcast Enhance (manual), then remux the enhanced wav back onto the video before transcribing or editing. Sync gotcha: `memory/extrair_audio_tool.md`.
- **Adobe Podcast, public package** — the same flow (extract, enhance, swap the audio, picture copied) packaged so any agent can run it. There is no clone of that package required on this machine. For this project's `raw/` plus `edit/` layout, keep using `ferramentas/adobe-enhance/`. Detail: `memory/adobe-podcast-repo-publico.md`.
- **transcrever** (isolated environment in `ferramentas/transcrever/`) — local transcription with a guard against dropped speech. Use it when `transcription` is `whisper`. `transcrever.py <video> -o base.json` (engine `whisperx` by default; `--motor vad|janela`; `--verificar` runs 2 engines and diffs them), `comparar.py` (diff two transcripts), `glossario.py` plus `glossario.json` (names the model always gets wrong). **Do not use `transcribe.py` from `local-video-use`.** The whisper.cpp `-dtw` path drops a segment of speech and does not say so. whisperx runs on CPU (about 3–5 minutes for 2 minutes of audio). The first run downloads a few GB into the model cache. If `transcription` is not `whisper`, use the configured provider and do not write a secret into the repo. SOP: `.claude/skills/transcricao-confiavel/SKILL.md`. Measurements: `memory/diretrizes-transcricao.md`. Gotchas: `ferramentas/transcrever/README.md`.
- **Grok CLI** (`grok`, installed on the machine — not a script in this project) — headless via `grok -p "<search>" --output-format json --no-alt-screen`. It has returned live X posts with a real link, date, and engagement, which is better X coverage than `last30days` on a bad day. `minet` and Scrapling do not cover X. It is not free (about $0.28 per search). **Never pass the always-approve flag.** Do not use it as a required research source. X coverage is not a separate switch in `memory/config.md`. Image generation is the `grok_image` switch, and it is not a source of posts. Wrapper for images: `ferramentas/grok-imagem/gerar.sh`. Prompt rules: `memory/prompt-imagem-fotografico.md`. Detail: `memory/grok_cli_tool.md`.
- **Research collection** — one agent frames the question, runs only the tools enabled in `memory/config.md`, reads the files it produced, and writes `referencia/pesquisas/<slug>/RESUMO.md`. There is no required second agent. Workflow: `.claude/commands/pesquisar.md`. After collecting, list the files and open any link or number that will be cited. A missing file is a gap, not a result.
- **MoneyPrinterTurbo — evaluated and removed.** A fully faceless stock short. Each piece it assembled is already covered by an on-brand skill (`media-use`, `embedded-captions`, the caption spec in `memory/hyperframes_caption_style.md`, `local-video-use`). The only thing it did alone (build a whole video from a topic) produces a generic video, which does not fit a brand that puts a real person on camera when `face` is `yes`. Notes, if the file is still present: `memory/moneyprinterturbo_smoke_test.md`.
