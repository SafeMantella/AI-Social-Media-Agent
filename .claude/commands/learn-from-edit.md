# Learn from an edit

Read this file and follow it. It is a workflow. Use it when the creator pastes their own version of something you drafted (a caption, a script, on-screen text), or says "this is how I would write it".

1. Take the draft you gave and the creator's version. Do not edit their text. If they only pasted one, find the draft in the store (`conteudo/`) or in this chat.
2. Compare them line by line. Extract rules about structure, order, what was cut, what was added, wording, and anything they disguised or removed. State each rule as something a text can be checked against.
3. Name the **surface** (Spoken, Caption, or On-screen text). A rule belongs to that surface only.
4. Save, in this order: the creator's version, whole, with the date and a one-line label, as a before-and-after in `memory/estilo-de-escrita/exemplos.md`; then the rules, numbered, under "Learned from edits" in `memory/estilo-de-escrita/guia-voz.md`, each with the date.
5. Any rule that is your interpretation and not obvious from the diff (for example "the warning is removed from the caption: always, or only here?") is marked `(inferred)`. Ask the creator to confirm the **two riskiest** in one message. Do not ask about all of them.
6. Fix factual errors the new version introduced (`memory/checagem-de-afirmacoes.md`), but report them and leave their text as they wrote it unless they ask.
7. Say in one line what you saved and where. Do this without being asked: it is the main way this system learns the creator's voice.
