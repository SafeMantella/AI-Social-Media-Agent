# Start a session

1. Read only `memory/pendencias.md` and `memory/project_social_media_status.md`. Do not read an index, a changelog, or a strategy doc now.
2. Answer in at most five lines: what is pending, highest priority first.
3. Ask where the creator wants to start. Wait for the answer before you load any other file.

The session-start checks in `AGENTS.md` (storage review, toolkit update, evolution report) still come first when one is due.
