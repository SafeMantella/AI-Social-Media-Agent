# Check skills

Read this file and follow it. It is a workflow. Run it only when `status` in `memory/config.md` is `ready`.

If `ferramentas/Pytho-inator/pytho-inator` is missing, clone `https://github.com/SafeMantella/Pytho-inator.git` into `ferramentas/Pytho-inator`, make the wrapper executable, and continue. Do not edit the clone.

Follow the check section of `ferramentas/Pytho-inator/skills/pytho-inator/SKILL.md`, in this order:

1. Run `ferramentas/Pytho-inator/pytho-inator check` with the root in `$ARGUMENTS` (empty means this folder). Do not read every skill.
2. Read `ferramentas/Pytho-inator/skills/pytho-inator/references/cli-contract.md`.
3. For each hit, say what the CLI replaces, and what stays in the skill when `judgment=keep`.
4. Stop. Do not edit a skill or write a script until the creator picks one. A yes follows the build section of that skill.
