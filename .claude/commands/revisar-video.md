# Review a video

Read this file and follow it.

1. Run `ferramentas/prep-frames/prep-frames` on the video. Read `sheet.jpg` and `resumo.md`. Do not open the loose frames.
2. If a `.leitura.txt` sits next to the transcript JSON, read that file. Do not read the word-level JSON.
3. Open one full frame only to measure an overlay in pixels.
4. Report problems with timestamps, and the correction you would make. Do not edit until the creator approves.
